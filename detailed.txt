================================================================================
  SECTION 6: ZERO-AMNESIA MEMORY ARCHITECTURE & SESSION CONTINUITY
================================================================================

6.1 The 10-Minute Session Refresh Problem Explained
Google Gemini Live WebSocket connections have an inherent infrastructure timeout of 10 to 15 minutes.
Upon session expiration, the client must reconnect. In naive implementations, this causes total amnesia:
the agent greets the user like a stranger, forgets active code tasks, and loses conversational context.

6.2 SARA's Zero-Amnesia Engineering Resolution
To eliminate this limitation, SARA implements a multi-tier memory architecture:

1. Module-Scope Dialogue Buffer (server.cjs):
   - Moved dialogueHistory from the local WebSocket connection scope to persistent module scope.
   - Dialogue turns accumulate continuously across multiple reconnection cycles.

2. WorkingMemoryCore (sara_neural_brain.py):
   - Persists state to d:\MARAA AI\SARA\resources\app\data\working_context.json.
   - Tracks active_task, current_project, recent_actions, and a 30-turn dialogue sliding window.

3. Reconnection Preamble Injection:
   - Upon session re-establishment, server.cjs automatically injects a high-priority continuity preamble:
     "[CONTINUITY CONTEXT RESTORATION — DO NOT BREAK FLOW]:"
     "You are continuing an ongoing session with Pasha Dev. A routine 10-minute refresh occurred."
     "ACTIVE TASK: <current_task> | RECENT ACTIONS: <actions> | RECENT TURNS: <turns>"
     "MANDATORY: Seamlessly continue from the exact discussion above without greeting him anew!"

6.3 Three-Tier Memory Taxonomy
- L0: Working Card   : In-memory active task state, project directories, and pending user requests.
- L1: Semantic Store : 18 canonical facts in memories.json (identity, pronunciation, brands, hardware).
- L2: Episodic Memory: Permanent append-only JSONL log (episodic_memory.jsonl) capturing timestamped interactions.

8.1 Desktop Path Resolution Architecture
A critical bug discovered in the decompiled MYRAA codebase was relative path misdirection:
When asked to create Desktop/game, the system created d:\MARAA AI\SARA\resources\app\Desktop\game.
To permanently solve this, SARA implements resolve_user_path:

```python
def resolve_user_path(raw_path: str) -> Path:
    clean = str(raw_path).strip().replace('\\', '/')
    if clean.startswith('~'):
        return USER_PROFILE / clean[2:].lstrip('/')
    parts = clean.split('/')
    first_lower = parts[0].lower()
    if first_lower in ['desktop', './desktop', '.desktop']:
        sub = '/'.join(parts[1:])
        return REAL_DESKTOP / sub if sub else REAL_DESKTOP
    p = Path(raw_path)
    if p.is_absolute():
        return p
    return REAL_DESKTOP / raw_path
```
